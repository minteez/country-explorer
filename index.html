About Country Explorer

What this is

Country Explorer is a small, focused tool for looking up country data — capitals, currencies, languages, borders, memberships, and more — without digging through spreadsheets or Wikipedia infoboxes.

The data source

Every result comes from the REST Countries API, a structured, normalized dataset of 90+ fields per country, reviewed weekly against ISO, UN, and Wikidata sources.

How the app works

This is a single-page app built with plain HTML, CSS, and JavaScript — no frameworks. A dedicated API layer handles every request; the rest of the app just renders whatever JSON comes back.

Technologies

  • HTML5
  • CSS3 (custom properties, no framework)
  • Vanilla JavaScript (ES modules-free, browser-native)
  • REST Countries API v5
